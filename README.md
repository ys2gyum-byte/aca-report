# 입반테스트 성적표 생성기

영재학교 대비 입반테스트의 채점 → 분석 → 개인별 성적표(코멘트 포함) 발행까지 한 화면에서 처리하는 웹앱입니다.
파일은 `public/index.html` **하나**뿐입니다. 서버도, 빌드도 없습니다.

## 쓰는 순서

구조는 **시험(회차) → 시험지(응시 유형) → 응시자** 3단계입니다.

1. **① 시험 정보** — 맨 위에서 **시험(회차)** 을 고릅니다. `+ 새 시험`으로 3월 입반테스트, 9월 모의고사처럼 회차를 나눠 만들 수 있고, 시험명·유형·날짜·대상 학교는 **시험마다 따로** 저장됩니다. 학원명·연락처·하단 문구는 모든 시험에 공통입니다.
2. **② 시험지 구성** — 먼저 **시험지(응시 유형)** 를 고르고, 그 시험지의 과목별 문항 수·배점·평가 단원·세부 평가 요소를 적습니다.
   - 응시 유형이 여러 가지면 `+ 새 시험지`로 여러 개를 만듭니다. 문항 수·배점·단원은 시험지마다 완전히 따로 관리됩니다.
   - `이 시험지 복제` — 같은 구성으로 하나 더 만듭니다 (응시자는 복사되지 않습니다).
   - `다른 시험지 양식 가져오기` — 이미 만든 시험지의 구성을 현재 시험지로 옮겨옵니다.
     **전체 구성** / **단원·평가 요소만** / **배점만** 중에 고를 수 있어, 문항 수가 같은 시험지를 빠르게 채울 때 씁니다.
   - `표 붙여넣기` 는 `문항유형` 열을 알아보고, 문항분석이 `[서술형] …` 처럼 시작하면 그 부분을 유형으로 자동 분리합니다.
   - `칼럼 설정` — 성적표 문항별 정오표에 넣을 항목(과목·세부과목·**문항 유형**·단원·평가 요소·배점·문항 평균·정답률·난이도)을 직접 고릅니다. 문항 유형은 객관식 / 단답형 / 서술형 / 논술형 / 추론형 등을 자유롭게 적습니다. 여기서 켠 항목은 구성 표에도 같이 나타납니다.
   - **문항 번호 순서대로** 보기로 바꾸면 물리·화학이 섞인 시험지를 한 표에서 편집합니다. 각 행의 **과목 칸을 고치면 그 문항이 해당 과목으로 옮겨지고 채점 결과도 함께 따라갑니다.** 행 끝의 ✕로 문항을 지우고, `+ 문항 추가`로 늘립니다.
   - 통계·석차·난이도·평균은 **같은 시험지 응시자끼리만** 비교합니다. 시험지가 다르면 서로 섞이지 않습니다.
3. **③ 성적 입력** — 위에서 고른 시험지의 응시자만 표시됩니다. 셋 중 편한 방법으로:
   - 표에서 셀을 눌러 `O → △ → X` 로 채점 (키보드 `1` `2` `3` `0`, 방향키 이동)
   - 「점수 직접」 모드로 문항별 점수 입력
   - 「엑셀 양식 받기」 → 채워서 「엑셀 업로드」
4. **④ 분석** — 평균·편차·분포, 문항별 정답률과 난이도, 단원별 성취도, 순위가 자동으로 나옵니다.
5. **⑤ 성적표** — 학생을 고르고 **PDF**(인쇄 → PDF로 저장) 또는 **이미지**(여러 명이면 ZIP)로 한 번에 발행합니다.
   카카오톡으로 보낼 때는 이미지가 편합니다.

## 자동 코멘트

총평은 점수만 보고 쓰는 것이 아니라 다음을 계산해서 문장으로 만듭니다.

- 과목별 위치(평균 대비, 표준점수)와 과목 간 편차
- 단원별 득점률과 응시자 평균의 비교 → 강점 단원 / 보완 단원
- 문항 난이도(응시자 정답률 기준) 대비 결과
  - 쉬운 문항 실점 → **실수·검토 습관** 지적
  - 어려운 문항 부분점수 → **접근은 했으나 완결 부족**
  - 어려운 문항 정답 → **심화 해결력** 강점
- 무응답 수 → 시간 운영 점검

문장은 `잘된 점 / 보완할 점 / 다음 학습`으로 나뉘어 인쇄되고, ⑤ 탭의 **코멘트 편집**에서 학생별로 고칠 수 있습니다.
고친 뒤 「자동 생성으로 되돌리기」를 누르면 원래대로 돌아옵니다.

## 데이터 보관

- 기본: **이 브라우저 안에만** 저장됩니다. 서버로 나가지 않습니다.
- 공동작업: 상단 **☁︎ 공유 설정**에서 Firebase(구글 무료 DB)를 한 번 연결하면 실시간으로 함께 봅니다.
  - **개인 일정 앱(gyumhub)과는 반드시 다른 Firebase 프로젝트**를 쓰세요.
  - 열람 허용 구글 계정을 적으면 화면에 맞는 Firestore 보안 규칙이 자동으로 만들어집니다. 그 규칙을 콘솔에 붙여넣어야 실제로 차단됩니다.
- 백업/이동: 상단 **데이터 → 파일로 내보내기(.json)**

## 수정 · 배포

수정은 Claude에게 말로 요청하면 됩니다. 배포는 한 줄입니다.

```bash
./deploy.sh "무엇을 바꿨는지 한 줄"
```

- 처음 한 번만: Netlify 토큰 등록 `security add-generic-password -a "$USER" -s report-netlify -w`
- 첫 배포: `SITE_NAME=원하는주소 ./deploy.sh "첫 배포"` → `원하는주소.netlify.app`
- 이후: 위 한 줄이면 됩니다. 사이트 정보는 `.netlify-site` 파일에 저장됩니다.
